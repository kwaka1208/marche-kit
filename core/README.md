# core/ — Halle（市場の屋根）

仕組みの本体。すべてのイベントで共通で、原則として編集しません。

## 構成

```
core/
├── i18n/       # 表示文言の辞書(ja.json / en.json)                    ← 済
├── php/        # 出店者情報の受信・保存、お知らせ書き込み、メール送信  ← 済
├── editor/     # 出店者エディタ、お知らせエディタ                      ← 済
└── js/         # サイトの描画(カード・ポップアップ・フィルタ・シャッフル・フォーム) ← 済
```

### js/ の中身

テーマのHTMLから読み込むのは `marche.js` の1行だけです。

```html
<script type="module" src="js/marche.js"></script>
```

| ファイル | 受け持ち |
|---|---|
| `marche.js` | 入口。読み込みの順序、`data-i18n` と `data-marche-text` の差し込み、失敗時の表示 |
| `config.js` | サイト設定と辞書、`t()`、対価の整形、販売日の表記、商品の掲載範囲（決定18） |
| `data.js` | ロスターと店舗データの取得・組み立て |
| `shops.js` | 出店者カードと店舗ポップアップ |
| `items.js` | 商品カード、フィルタ、「もっと見る」、商品ポップアップ。**出す範囲は `items.display` が決める** |
| `announcements.js` | お知らせ |
| `social.js` | イベント公式のSNSリンク（決定12） |
| `form.js` | 問い合わせフォーム。組み立て・検証・確認モーダル・送信（決定13） |
| `popup.js` | ポップアップの開閉（商品用と店舗用で共通） |
| `ui.js` | ナビゲーション、ページ内リンク、FAQ |
| `util.js` | シャッフル・取得・テキストと画像の差し込み・セクションを隠す（ナビゲーションの項目ごと） |

ESモジュールなのでビルドは要りません。**そのまま公開ディレクトリに置いて動きます。**

## コアが守る約束

### 見た目を決めない

**決められたクラス名とDOM構造を出力する。見た目は決めない。**

色・余白・フォントをコアのコードに書いてはいけません。
それはテーマ（[`themes/`](../themes/)）の領分です。
仕様の詳細は [docs/theme-contract.md](../docs/theme-contract.md) を参照してください。

例外は [`editor/editor.css`](editor/README.md) です。エディタは来場者が見る画面ではなく
運営と出店者が使う管理ツールなので、テーマの対象外として見た目を同梱しています。

### 文言を直書きしない

画面に出す文字列は `i18n/` の辞書から引きます。
サイト設定の `locale` でどの辞書を使うかが決まります。

| どこから引くか | 書き方 |
|---|---|
| PHP | `marche_text('server.badShopId')` |
| エディタJS | `t('editor.itemName')` |
| エディタHTML | `data-i18n="editor.itemName"` |

`ja.json` と `en.json` は**キー構造を完全に一致させてください。**
辞書を追加するときは既存のキーをすべて埋めます。

`{name}` `{label}` `{max}` `{value}` はプレースホルダで、実行時に置き換わります。

### イベント固有のことを書かない

開催日・カテゴリ・対価の単位・通貨は、すべて `marche.config.json` と
`data/shops.json` から読みます。コードに直接書いてある年・日付・カテゴリ名があれば、
それは移植の漏れです。

### 秘密情報を持たない

通知先メールアドレス・管理キー・Webhook URLを**このフォルダのファイルに書かないでください。**
`.env` に置き、`tools/inject-env.py` が配置先へ流し込みます。
詳細は [php/README.md](php/README.md) を参照してください。

## サーバーとクライアントで揃える定数

画像の上限サイズ・許可拡張子・商品の販売状態は、`php/config.php` と
`editor/editor.js` の両方に定数があります。
**片方だけ変えると、エディタを通ったデータがサーバーで弾かれます。**

商品の販売状態（`onsale` / `soldout` / `ended`）は `js/data.js` にもあり、
**3箇所を同時に直す必要があります。** ここがずれると、保存はできるのに
サイトに出ない（またはその逆の）商品ができます。

## 配置するときの置き場

コアとテーマを公開ディレクトリへ配る位置です。`js/` の中のパス定数がこれを前提にしています。

```
<公開ディレクトリ>/
├── index.html          ← themes/<テーマ>/index.html
├── css/                ← themes/<テーマ>/*.css
├── images/             ← themes/<テーマ>/images/
├── js/                 ← core/js/
├── i18n/               ← core/i18n/
├── editor/             ← core/editor/
├── marche.config.json
└── data/               ← core/php/ + shops.json + news.json + shop-data/
```
